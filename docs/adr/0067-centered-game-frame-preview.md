# Present the current game scene in a centered preview frame

The central Camera Animation Editor viewport presents the current client game scene as a Game Frame Preview rather than as a separate modeling canvas. The selected camera animation is evaluated through the editor-owned local preview camera, and the resulting view is scaled to fit the available central frame, kept aspect-preserving, and centered. A compact Viewport Control Bar occupies its own strip above the rendered frame. Dark charcoal letterboxing or bounded empty margins are preferable to stretching, overlaying controls across, or cropping important camera content.

This presentation remains isolated from the player's actual gameplay camera, player movement, capabilities, and server runtime state. If the current dimension or safe live scene cannot be rendered, the existing Abstract Stage Preview is used as an explicit fallback while preserving the same centered-frame contract. All editor overlays, including trajectories, view-space nodes, frustum, guides, collaborator indicators, and Gizmo handles, are rendered inside the Game Frame Preview as world-space or camera-projected scene geometry using the same preview camera. They are not moved into a separate director view, Picture-in-Picture window, or detached overlay canvas.
