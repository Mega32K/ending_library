# Model Bézier as adjacent timeline node chains

Bézier authoring is represented by ordinary timeline keyframe nodes whose adjacent membership determines a Bézier Node Chain, not by a separate node silhouette or a whole-track preset. A chain requires one track, temporal adjacency, and no intervening keyframe or non-Bézier node. With exactly two adjacent Bézier nodes, the interval is deliberately rendered and evaluated as `LINEAR`; with three or more, the graph renders the continuous Bézier result and permits editing the interior incoming and outgoing handles. Compact Timeline Mode supports insertion and ordinary node operations without handle controls, while Graph Editor Mode provides precise curve authoring. Insertion, deletion, and time movement deterministically recompute chain membership after the edit; the operation does not sample or fit the previous trajectory, does not delete authored node data, and commits the complete structural change as one Undo/Redo transaction. Node selection, hover state, and diamond appearance remain unchanged.
