# Define mode-dependent keyframe dragging

Compact Timeline Mode treats a keyframe drag as a horizontal time edit; vertical pointer movement does not modify the authored value. Graph Editor Mode permits horizontal time editing and vertical authored-value editing for the selected scalar track. Multi-selected nodes move as one gesture while preserving their relative offsets, configured snapping applies to time changes, and releasing the pointer submits one atomic edit transaction. The field written by a timeline, graph, or world-space operation is resolved from the selected track's verified camera modifier identity; the editor never infers `TRANSLATION_*` versus `RELATIVE_*` from screen or world position. With no keyframe selected, world-space editing follows the current playhead pose rule already defined by the editor.
