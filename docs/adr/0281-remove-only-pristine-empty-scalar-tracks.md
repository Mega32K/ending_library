# Remove only pristine empty scalar tracks

Remove Empty Tracks targets only a Pristine Empty Track: an instantiated Scalar Animation Track whose Additive Lanes contain no accepted keyframes and whose stored Lane structure is either absent or exactly one untouched system-created default empty Lane. A keyed track remains nonempty even when every authored value evaluates to zero. An imported Legacy Group Lane named `default` is authored import structure, not the system-default Lane, and is therefore protected.

Any non-default Lane name, multiple-Lane layout, user-adjusted Lane order, Legacy Group Lane identity, import or round-trip metadata, or other durable authored reference protects the complete track even when all its Lanes contain zero keys. Empty Lanes inside a nonempty track are not removed; a future Remove Empty Lanes operation would require its own design and preview. Track Groups, Command Animation Effect Event rows, and supported camera-channel definitions are never candidates.

Removing an eligible track deletes only redundant instantiated project storage. The channel remains available in the camera schema and is rematerialized with a new system-default Lane when the user later authors its first keyframe. Timeline visibility, collapse, color, filtering, and local selection do not count as authored content, but an active draft, gesture, lock, or valid operation reference temporarily protects the candidate until authoritative revalidation can safely remove it.

The Tool Operation Preview reports each removable track and each protected empty structure with its reason. A successful server-authoritative confirmation changes neither evaluated trajectory nor Animation Duration, commits all disclosed removals atomically as one project revision and personal Undo/Redo item, and allows Undo to restore the exact removed stored structure. A stale or newly protected candidate rejects or regenerates the complete preview rather than being silently skipped.
