# Refresh collaborators atomically after checkpoint restore

After a checkpoint restore commits, the server broadcasts the new full-document authoritative revision to every current collaborator for the project. Each open editable view applies one Restore Content Refresh: authored tracks, keyframes, curves, animation properties, command events, and markers are replaced as one coherent document update without closing the Project Tab or silently removing the participant from the Editing Session. An inactive local tab may defer visual application until its normal activation boundary, but it cannot continue authoring against the pre-restore content.

The refresh performs Restore Draft Invalidation for all local content-changing state whose baseline was the pre-restore document, including Animation Properties previews, Auto Key proposals, Command Event Creation Drafts, and active Gesture Previews. No client attempts a best-effort merge, submits the discarded draft automatically, or leaves a stale Project Tab Draft Dot. The server's accepted restored document remains authoritative; failed restore produces no refresh and no local draft loss.

Restore Selection Reconciliation keeps each player's playhead, playback or pause state, viewport, panel layout, and valid selection identities whenever those values remain meaningful. It removes only selections pointing to objects absent from the restored document and reports that cleanup through the local status surface. It does not force the restore target's playhead, start Collaborative Preview, change runtime publication, instantiate or stop a gameplay camera, or alter another player's local observation camera.

The initiating player's Difference Summary or restore confirmation surface closes with a success or failure result. Other collaborators receive a concise non-modal status notification identifying the restoring player and checkpoint; detailed restore metadata remains available through the Collaboration Status Area. Personal Undo/Redo histories are retained and revalidated under the Restore Barrier rather than cleared.
