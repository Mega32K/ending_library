# Make converted Bézier output ordinary and editable

After an Easing-to-Bézier Simulation is confirmed, every retained source keyframe and every inserted fitting keyframe becomes an ordinary Timeline Bézier Node. Stable identities, authored times, and authored values of existing source nodes are preserved; inserted nodes receive ordinary identities and no persistent generated/provenance marker is required for rendering or editing. The resulting chain supports the same movement, multi-selection, clipboard, deletion, Graph Editor handle editing, collaboration validation, and Undo/Redo behavior as a manually authored Bézier chain. Later edits never trigger hidden re-simulation, automatic node regeneration, or provenance-specific visuals; removing an inserted node is a normal user edit.
