# Separate the project catalog from project documents

Persist the world-level project catalog as `SavedData` and persist each animation project's content in its own versioned JSON document with a recovery backup and project-local operation journal. The catalog owns identity, ownership, permissions, lifecycle, and revision metadata; the project document owns animation tracks, keyframes, and editor data. Project Catalog Queries page and filter catalog metadata without loading every Project Document, and a document is loaded only after the chosen entry passes current permission and format checks. Accepted collaborative operations are journaled in server order between atomic document snapshots. This keeps large projects isolated, limits unrelated rewrites, and gives the server a clear boundary for atomic save, journal compaction, and crash recovery.
