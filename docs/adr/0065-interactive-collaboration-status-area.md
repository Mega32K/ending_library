# Make collaboration status an interactive editor surface

The Camera Animation Editor exposes a detailed Collaboration Status Area in the bottom Editor Status Bar and a compact Workspace Bar Status Entry in the fused top project-tab surface. The detailed area reports connection, synchronization, participant, role, collaborative-preview, conflict, persistence, lock, and diagnostic state through semantic icons, concise text, shape, and focus feedback rather than color alone. Neither the top project tabs nor their compact entry displays the internal project revision as ordinary tab content; revision details are available from the bottom status surface.

Opening the detailed status area exposes real participant and session details, remote presence, preview state, conflict information, restore-origin notifications, current revision and persistence state, active command-event locks, and the recovery or resynchronization actions valid for the current state. A successful checkpoint restore is reported to non-initiating participants as a concise Session Collaboration Notification here; selecting it opens read-only Restore Notification Detail and never forces a playhead seek, preview join, or gameplay-camera change. Notifications are bounded and session-scoped, with older records removed deterministically; they are not written to the project or a permanent chat log. Narrow layouts collapse the area into icon badges or a responsive drawer. A decorative status light or non-functional participant panel is not sufficient.
