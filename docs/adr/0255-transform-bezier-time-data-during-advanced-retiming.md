# Transform Bézier time data during advanced retiming

Advanced Retiming treats Bézier data as authored time geometry rather than as a curve to bake or resample. Offset and non-reversing scale move eligible node times while preserving each active or dormant handle's normalized segment time and unit-aware track value; `AUTO` tangent modes remain `AUTO` and are deterministically reevaluated only after the final sorted topology is known. A segment with only one in-scope endpoint receives no synthetic boundary node, so its exact proposed shape change must be visible in the Tool Operation Preview.

Reverse mirrors eligible node times and, for every fully covered Curve Segment, exchanges incoming and outgoing handle data and maps normalized handle time through `u -> 1 - u`. Side-specific tangent relationships move with their corresponding sides, dormant curve data is transformed with active data, and Bézier Chain Reconfiguration runs after the transformed order is resolved. The complete operation preserves a fully covered curve as the previous trajectory traversed backward within numeric tolerance and commits as one atomic revision and Undo/Redo item without hidden fitting.
