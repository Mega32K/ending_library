# Use explicit selection-first scopes for empty-track cleanup

Remove Empty Tracks uses one visible Empty-Track Cleanup Scope: `Selected Tracks`, `Current Animation`, or `Whole Project`. When the current selection contains an instantiated Scalar Animation Track or Track Group, `Selected Tracks` is the default and a selected group expands to its instantiated scalar descendants. The selected set may contain nonempty or protected tracks so the preview can explain their exclusion; only Pristine Empty Tracks become removal candidates.

Without a valid track or Track Group selection, the tool opens with no scope chosen and never silently falls back to Current Animation. The user must deliberately select `Current Animation` or `Whole Project`, and Whole Project is never a default. These choices are mutually exclusive rather than implicitly intersected with selection. Work Range, Custom Range, Timeline Channel Visibility, filtering, row virtualization, and viewport presence do not participate because emptiness is structural rather than temporal or visual.

Current Animation resolves only instantiated scalar tracks in the Current Edited Animation. Whole Project resolves every instantiated scalar track across the project and groups preview results by animation. The Tool Operation Preview identifies removable Pristine Empty Tracks, authored-structure protection, and temporary activity or reference protection. If no candidate is removable, confirmation is disabled and no empty revision or Undo/Redo item is created.

Confirmation sends the declared scope, project baseline, animation identities, and stable track identities for authoritative re-resolution. A relevant track, Lane, keyframe, draft, lock, reference, animation, or project-structure change invalidates the complete preview; the server never silently drops a stale candidate or broadens the scope. One accepted cleanup removes every disclosed candidate atomically in one project revision and personal Undo/Redo item.
