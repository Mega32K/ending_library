# Stack animation resources above the current track tree

The left navigation stack participates in the Responsive Degradation Order in ADR-0205: it may become a real drawer or Panel Tab Group only after the Core Editor Region and right inspector have been protected, and it retains both panels' independent state.

The default Camera Animation Editor layout uses a Left Animation Navigation Stack. The Animation Resource Browser occupies its upper region and the Timeline Track Tree Surface occupies its lower region, separated by a bounded draggable vertical splitter. They share the left Dock Zone width but remain independent panels with separate focus, scroll, filtering, disclosure, visibility, docking, and restoration state. The Timeline Track Tree Surface is a synchronized companion to the bottom Timeline Panel rather than a second timeline: its rows align with the right-side lane canvas, while the lane canvas, ruler, playhead, curves, and transport remain part of the bottom Core Editor Region.

A single click on an animation resource establishes the Current Edited Animation and performs Animation Switch Synchronization. The editor captures the previous animation's Animation Timeline View State, restores the selected animation's valid state, and updates the Camera Track Tree, lane canvas, graph curves, playhead evaluation context, viewport preview, local selection, and Contextual Property Inspector together. This navigation does not create a project revision, start or stop local preview, enable a runtime animation, publish content, or enter personal Undo/Redo. Selecting a track, keyframe, curve, marker, or command event changes only selection inside the already current animation and never switches the Animation Resource Browser to another resource.

Animation Timeline View State is keyed by player, project, and animation within the connected Project Workspace Layout lifecycle. It retains the logical timeline display set, track-group expansion, timeline and graph scroll or zoom, playhead time, presentation mode, and valid selected identities. If collaboration deletes or replaces an identity while its animation is inactive, restoring that animation discards only the invalid local reference and reports the unavailable target instead of selecting a different object. The state is not Project Document content, animation JSON, a checkpoint, a collaboration operation, runtime state, or personal edit history, and it is cleared on server or world exit and disconnection.

Closing or hiding the Animation Resource Browser leaves the Current Edited Animation and Timeline Track Tree Surface usable. Closing or hiding the Timeline Track Tree Surface leaves the Animation Resource Browser and Timeline Panel lane canvas usable through toolbar, context-menu, shortcut, and Contextual Property Inspector routes. The View Menu restores either panel independently. On narrow layouts the two panels become a real Panel Tab Group or drawer rather than being compressed into unusable lists; their states remain separate. Neither panel gains persistent hover or selection action buttons, and every operation remains available through its established non-inline entry points.
