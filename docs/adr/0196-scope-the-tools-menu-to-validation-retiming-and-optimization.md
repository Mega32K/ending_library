# Scope the Tools menu to validation, retiming, and optimization

The top toolbar exposes a Tools Menu for advanced operations that do not belong in ordinary keyframe editing, project lifecycle, or display settings. It contains three groups. Validation defaults to the current animation or focused authoring scope and exposes an explicit Whole Project switch; it runs as a bounded, cancellable background check with truthful phase status and provides read-only checks including timing and curve consistency, supported runtime-data validity, resource-budget diagnostics, and Legacy Animation Format or Extended Camera Animation JSON compatibility reports. Advanced Retiming provides exact offset, time scaling around an explicit anchor, and reversal over one explicit Retiming Target Scope. An eligible Selection defaults ahead of Work Range, both can be chosen explicitly when available, neither is silently intersected with the other, and the tool never falls back to the whole animation. Bake and Optimization provides preview-first baking of evaluated results into authored keyframes, removal of redundant keyframes only when the proposed trajectory error remains within the chosen tolerance, and removal of empty tracks.

A completed Validation Report shows its scope and terminal status with complete Error, Warning, and Information counts. Each Validation Finding receives a stable semantic severity: Error for invalid or unusable checked content, Warning for valid but risky, lossy, or resource-concerning content, and Information for correctness-neutral observations or optimization opportunities. Findings are grouped first by severity and then by stable diagnostic code, with Whole Project results additionally divided by animation; header and group totals always represent all findings found by a successful complete scan. Retained focusable details are generously but finitely bounded overall, per severity, and per diagnostic code; reaching that budget produces a visibly Details-Limited report with total-versus-retained counts and narrower-scope rerun actions rather than silent truncation or an unbounded Load More path. Error begins expanded while Warning and Information begin collapsed; severity and text filters change only local presentation and truthfully cover retained details, while selecting a valid finding focuses its existing editor target without editing or seeking playback. A later accepted project-content change marks the report outdated without exposing an internal revision number or starting validation automatically; an explicit rerun keeps the outdated report visible until a matching successful result replaces it. Every mutating tool first creates a bounded Tool Operation Preview containing its target scope, baseline revision, proposed changes, resource impact, and trajectory or compatibility metrics; only explicit confirmation submits the result. The server repeats permissions, locks, revision, format, marker, duration, curve, resource, and finite-value checks before accepting one atomic project operation and one personal Undo/Redo item. Cancellation, stale baselines, disconnects, resource-budget failure, or rejected confirmation leave the project and history unchanged. Tools never publish, silently export, execute test commands, perform automatic repair-all, or convert `TRANSLATION_*` and `RELATIVE_*` tracks without an explicit world-context design and preview.
