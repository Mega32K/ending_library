# Confirm curve modes through purpose-built selectors

These selectors are the controls of the Keyframe Menu's Curve and Tangent group and remain subject to the complete-selection validity rule.

Curve Interpolation Mode uses a compact Blockbench-styled dropdown with a fixed `EASING_PRESET`, `BEZIER`, `LINEAR`, and `CONSTANT` order, while each Bézier boundary uses a four-part `AUTO`, `ALIGNED`, `MIRRORED`, and `BROKEN` Tangent Mode selector. Mouse and keyboard users may open and browse these controls without mutating the project; only `Enter`, `Space`, or an explicit pointer choice confirms one atomic Undo/Redo operation, and `Esc` cancels. Scroll-wheel mode changes are disabled, selection blue remains distinct from keyboard focus, numeric-keypad field navigation applies only inside numeric fields, and responsive icon-only rendering must retain complete labels and descriptions.
