# Default Bake to adaptive error-bounded sampling

Bake defaults to a deterministic Adaptive Error-Bounded sampling mode instead of deriving its sample grid from timeline zoom, snapping, or Display Frame Rate. For every participating Additive Lane, exact Bake Time Scope endpoints, all in-scope source keyframe times, and discontinuity boundaries are mandatory samples. The sampler then refines intervals at deterministic greatest-error locations until reconstruction under the selected Bake output interpolation satisfies the unit-aware fidelity target, while a finite maximum sample gap guards against missing short-lived variation.

An explicit Fixed Interval alternative supports intervals expressed in logical seconds, game ticks, or display frames. Display Frame Rate is consulted only to convert a user-selected frame interval; changing it never alters the default adaptive result. Fixed grids still include mandatory samples and exact scope endpoints when those times do not coincide with the interval. Equal authoritative input, scope, settings, and resource budgets must produce the same ordered sample set on every participant and the server.

The Tool Operation Preview shows the resolved mode, fidelity target or interval, maximum gap where applicable, mandatory and generated sample counts, resulting node count, measured maximum error, and relevant resource consumption. If the requested fidelity cannot be reached within server limits, confirmation is disabled with the limiting reason; Bake never silently loosens tolerance, omits mandatory samples, truncates output, changes modes, or commits a partial subset.
