# Use a hybrid live-world and abstract 3D preview

The Camera Animation Editor renders the selected project revision in a centered, aspect-preserving Game Frame Preview inside the Embedded Preview Viewport, using a client-owned preview camera whenever the recorded Preview Stage dimension and safe client world rendering are available. The Viewport Control Bar reports that live dimension through Preview Availability State. The view overlays the evaluated camera position, orientation, keyframe nodes, trajectory, Preview Stage axes, field-of-view frustum, zoom range, and raycast distance. Local orbit, pan, follow, and reset controls change only Viewport Observation State and never move or retarget the player's gameplay camera.

When the dimension is unavailable or real-time world rendering cannot be used safely, the editor switches to an Abstract Stage Preview using the stored stage transform, grid, axes, trajectory, camera markers, and lens overlays. The state change is explicit and visible; the fallback never substitutes a participant's current location and never mutates project content or runtime camera state. Collaborative preview shares revision and stage evaluation, while each participant keeps an independent observation viewpoint.
