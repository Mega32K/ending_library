# Restore the full local preview snapshot

Before an `Explicit Collaborative Preview Join` applies shared state, the client captures one bounded `Local Preview Snapshot`. It includes the valid Current Edited Animation, playhead time, playing or paused state, loop state, work range, viewport observation, Animation Timeline View State, local track/keyframe/curve/marker/event selection, and relevant panel navigation. The snapshot is keyed to the current player, project, animation identities, and connected editor lifecycle; it is never sent as collaborator data or written to the Project Document.

When the participant invokes `Leave Collaborative Preview`, or when `Collaborative Preview Termination` ends the shared session, the client restores every still-valid part of that snapshot in one local transition. This includes restoring whether the local preview was playing or paused, but it never starts a gameplay-facing runtime instance, takes over the actual game camera, publishes a revision, or creates a project or personal-history operation. Shared preview playback ends independently from local restoration.

Restoration is identity-aware and bounded. If the selected animation, track, node, marker, event, or other target no longer exists, the client clears only that dependent selection; a playhead beyond the current animation duration is clamped to the valid end, and an invalid animation identity falls back to the ordinary no-animation or current-animation empty state. Missing or invalid panel targets use normal responsive state cleanup rather than guessed replacements. A connection, world, server, or editor-lifecycle exit clears the snapshot instead of restoring it across lifecycles, following the existing session-scoped workspace contract.
