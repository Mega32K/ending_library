# Execute command effects once with a silent runtime source

When a Command Animation Effect Event crosses its timestamp, the runtime dispatches its command exactly once for that crossing in that Project Runtime Instance. A selector inside the command payload may resolve multiple command targets, but target count never multiplies dispatcher invocations. The command source entity is the runtime instance's target player—the player currently playing the camera animation—using that player's live runtime position, rotation, dimension, and command execution context at the crossing. The source uses the fixed server Command Effect Permission Policy and is wrapped in a suppressed-output command source equivalent to the verified 1.20.1 `CommandSourceStack#withSuppressedOutput()` behavior: command success, failure, and feedback are not returned to the source player or editor UI. Command targeting belongs entirely to the payload, while runtime source identity remains a separate concern.
