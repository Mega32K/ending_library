# Initialize only new Bézier nodes with safe auto handles

A two-node Bézier Node Chain evaluates linearly and does not use or display handles, but any existing handle data remains dormant. When an insertion or chain join first produces three or more adjacent Bézier nodes, existing authored handles are restored without recalculation and only a newly introduced node without handle data receives deterministic `AUTO` handles. Initial Auto Handles derive a smooth tangent from neighboring node time and value data while preventing initial overshoot; they are initialization data rather than a selectable preset. Graph Editor Mode may subsequently author `ALIGNED`, `MIRRORED`, or `BROKEN` handles. Node creation, initialization, and chain reconfiguration remain one atomic collaboration revision and one Undo/Redo item.
