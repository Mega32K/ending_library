# Run command effects with a fixed server permission level

Command Animation Effect Events execute with one server-wide configured permission level whose initial default is level `2`. The runtime does not inherit the target player's current operator status, the Project Owner or Project Editor role, or a per-event permission value. The target player remains the command source entity and supplies live position, rotation, dimension, and `@s`, but the runtime replaces the source permission level with the server policy and suppresses all source output. Both project roles may author command events under the existing editing permission model, so validation and publication surfaces must clearly disclose that an accepted event can later execute with the configured server command authority. The editor and server validate command syntax and permission availability against the same policy before accepting or publishing executable content; clients cannot raise or bypass it.
