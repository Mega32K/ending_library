# Scope the Timeline menu to time, preview, and range controls

The top toolbar exposes a Timeline Menu divided into Preview Transport, Playhead Navigation, Exact Time Entry, Animation Duration, Project Timeline Markers, and Work Range groups. Preview Transport contains Local Preview play or pause and loop-mode controls. Playhead Navigation provides start, end, previous-keyframe, and next-keyframe seeking; Exact Time Entry accepts the active seconds, frame, game-tick, or timecode display without changing canonical Timeline Time; Duration exposes manual set, fit-to-keyframes, trim-to-Work-Range, and set-end-to-selected-keyframe operations; Markers exposes create, edit, delete, and seek actions; and Work Range exposes start, end, clear, reset, and selection operations. Every disabled action provides its established reason through the button or menu tooltip system.

The Timeline Menu does not absorb unrelated responsibilities. Display Frame Rate, time-display format, and default snapping remain under Settings > Timeline; Timeline Presentation Mode and other display-only switches remain under View; numeric keyframe content remains under the Keyframe Menu; publication remains under Animation. The accepted Stop entry is a visually separated alias of Stop Enabled Animation for Me and therefore retains Runtime Stop semantics: it terminates the UI Client Player's Project Runtime Instance and restores the camera without changing editor playhead, project content, or Active Runtime Revision. It is not a second pause, rewind, or return-to-zero command.
