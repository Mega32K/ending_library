# Separate curve interpolation from tangent coupling

The editor separates the way a Curve Segment is evaluated from the way Bézier handles are coupled at its keyframe boundaries. Curve Interpolation Mode is one of `EASING_PRESET`, `BEZIER`, `LINEAR`, or `CONSTANT`. Tangent Mode is one of `AUTO`, `ALIGNED`, `MIRRORED`, or `BROKEN`, and is meaningful only where a neighboring Bézier segment exposes handles.

`EASING_PRESET` preserves the existing named `Easing` behavior. `BEZIER` evaluates the authored cubic control points. `LINEAR` and `CONSTANT` are direct interpolation modes and hide or disable Bézier handles. Tangent Mode does not change the interpolation algorithm or the Legacy Easing Fallback; it only determines how editable handles at a boundary respond to a handle edit.

`AUTO` deterministically computes both sides from neighboring keyframes. `ALIGNED` keeps the incoming and outgoing handles collinear while allowing different lengths. `MIRRORED` keeps them collinear with equal lengths. `BROKEN` leaves both sides independent. When a mode couples two adjacent Curve Segments, the editor renders every affected handle during the active gesture, previews all affected curves, validates the complete set against the authoritative revision, and commits one atomic project operation. A conflict in any affected segment rejects the whole gesture.

Changing either mode is an authored project edit and one Undo/Redo item. Handle movement is also one Undo/Redo item per pointer gesture. The editor never applies a neighbor mutation merely because a segment is nearby; cross-segment changes occur only through the explicitly selected coupling mode.
When a user drags a visible handle at an `AUTO` boundary, the editor snapshots the currently computed handle positions, promotes the boundary to `ALIGNED`, and continues the same pointer gesture using aligned coupling. The promotion is not a separate history entry and must not cause a visible discontinuity before the drag delta is applied. Switching the boundary back to `AUTO` discards the manual coupling state for that boundary and recomputes both handles deterministically from the neighboring authored keys; that switch is its own authored Undo/Redo operation when performed outside the original drag.
Holding `Alt` when a handle drag begins is the explicit Tangent Break Gesture. It freezes the currently evaluated handles, promotes `AUTO`, `ALIGNED`, or `MIRRORED` to `BROKEN`, and moves only the grabbed side. The conversion and drag share one preview, validation footprint, revision, and Undo/Redo entry. Cancelling the pointer gesture or receiving a server rejection restores the previous mode and every affected handle.
The Curve Segment Inspector edits these concepts separately. It presents the segment's Curve Interpolation Mode first, then exposes start-boundary and end-boundary Tangent Mode controls only for `BEZIER`. Each boundary shows normalized handle time and value coordinates and explicitly names whether the preceding or following segment will also change. `AUTO` coordinates are read-only; beginning a direct numeric edit freezes the computed positions and promotes that boundary to `ALIGNED` under the same no-jump rule as a normal handle drag.
