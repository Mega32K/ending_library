# Give every keyframe interval an independent curve segment

The project format stores an explicit Curve Segment for each interval between neighboring keyframes. A segment references stable start and end keyframe identities, has an independent Curve Interpolation Mode, and stores normalized curve data when that mode requires it. Existing legacy `easing` values map to the segment ending at that keyframe, preserving the current runtime meaning in which the target keyframe selects the interpolation for the preceding interval.

Curve Interpolation Mode is separate from Tangent Mode. `EASING_PRESET` selects one existing `Easing` function, `LINEAR` evaluates a straight interpolation, and `CONSTANT` holds the preceding value until the segment boundary. Bézier participation is carried by adjacent Timeline Bézier Nodes: a chain of exactly two nodes deliberately evaluates and renders its interval as `LINEAR`, while a chain of three or more activates the authored cubic handles across the continuous chain. Tangent Mode applies only to active Bézier handles at a keyframe boundary: `AUTO` computes them from neighboring keys, `ALIGNED` keeps both sides collinear with independent lengths, `MIRRORED` keeps both sides collinear with equal lengths, and `BROKEN` keeps the two sides independent.

Normalized Bézier time handles remain within a valid forward interval so sampling cannot encounter a backward or zero-duration segment; value handles may overshoot to represent back, elastic, and bounce-like motion. Directly editing one segment does not alter another segment unless the selected boundary's explicit Tangent Mode couples their handles. In that case, every affected segment is included in the same transient preview, server validation, commit, collaboration footprint, revision, and Undo/Redo item. A handle drag never silently mutates an unrendered neighbor.

Extended Camera Animation JSON emits the complete versioned custom segment alongside its explicit compatibility `easing` fallback. A Legacy Animation Format export omits the custom segment and therefore requires the established downgrade-warning flow whenever the fallback is not an exact representation. The project format remains the complete multi-channel source of curve data.

This support is required in the initial editor release and is not a graph-only visual approximation. The authoritative project document, collaborative edit operations, revision snapshots, clipboard payloads, Undo/Redo entries, persistence representation, runtime publication payload, and camera evaluator must preserve and execute custom segment data losslessly. Dragging a control point uses transient local preview during the gesture and submits one atomic server-validated curve edit on release.

The Curve and Tangent group in the Keyframe Menu is the compact entry point for these explicit interpolation and tangent changes; it does not expose curve controls for selections whose complete target set cannot accept the requested mode.
