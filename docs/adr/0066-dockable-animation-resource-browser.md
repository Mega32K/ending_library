# Use a complete dockable animation resource browser

The rewritten Camera Animation Editor includes a left-side Animation Resource Browser as a real, dockable, responsive management surface for the current project's animations. Its default placement is the upper region of the Left Animation Navigation Stack. It supports search, filtering, sorting, creation, import, selection, rename, duplication, deletion, property editing, preview, and the valid local enable/stop actions through the existing transaction, permission, collaboration, and Undo/Redo rules. Selecting a resource establishes the Current Edited Animation and performs Animation Switch Synchronization without starting playback or editing project content. It remains distinct from both the world-level Project Browser and the Timeline Track Tree Surface.

The browser uses the Blockbench-inspired dark panel language, blue selection feedback, semantic state markers, automatic name selection for rename fields, and responsive collapse into an actual drawer or tabbed entry point. Large lists may virtualize visual rows without changing off-screen animation data or losing selection, focus, or scroll restoration. A static list or decorative toolbar is not a complete implementation.
