# Preserve independent Easing interval shapes at shared boundaries

Easing-to-Bézier Simulation approximates each source Easing interval independently rather than fitting the entire selected range as one global curve. Existing source keyframes remain exact in time and value, while shared boundaries default to `BROKEN`: the incoming handle belongs to the preceding interval and the outgoing handle belongs to the following interval, with no implicit C1 or C2 smoothing that could materially alter either source result. The converted chain is therefore at least C0 continuous at preserved keyframes, and any later smoothing is an explicit Graph Editor authoring action that enters its own Undo/Redo transaction. The conversion preview and fidelity report must expose this boundary behavior before confirmation.
