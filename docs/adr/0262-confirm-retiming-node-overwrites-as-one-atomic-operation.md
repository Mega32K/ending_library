# Confirm Retiming node overwrites as one atomic operation

Advanced Retiming treats a proposed scalar keyframe as colliding only when an unaffected resident keyframe occupies the same scalar track and exact canonical time, regardless of whether either node uses Easing, Bézier, Linear, or Constant interpolation. Different tracks do not collide, and Project Timeline Markers or Command Animation Effect Events retain their established same-time coexistence rules. The Tool Operation Preview groups every collision by track and time and identifies the moved node, resident node, affected Curve Segments, and resulting Bézier Chain Reconfiguration.

Submitting a preview with collisions opens one aggregate Blocking Transaction Surface with `Cancel` focused and `Overwrite and Apply` as the explicit destructive action; cancellation closes only that confirmation and preserves the editable preview. Acceptance keeps each moved node's stable identity, deletes every disclosed resident, applies curve reconfiguration and any duration extension, and records the entire Retiming plus overwrite result as one authoritative project revision and one personal Undo/Redo item whose undo restores all original nodes, times, duration, and curve structure.

Two participating moved nodes that normalize to the same track and canonical time make the candidate invalid rather than choosing a survivor. Commit-time validation resolves the collision set again; a resident added, removed, replaced, or changed after preview generation invalidates the prior consent and rejects the operation until a fresh preview and confirmation disclose the new exact footprint. No collision is skipped, silently overwritten, or approved by a remembered global preference.
