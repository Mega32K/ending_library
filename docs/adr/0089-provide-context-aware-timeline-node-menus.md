# Provide context-aware timeline node menus

Right-clicking a timeline node opens a compact Blockbench-styled dark context menu with blue hover highlighting. Opening or navigating the menu does not alter the node's rendered hover state and does not add inline controls to the timeline row. Numeric keyframes use the four-group Keyframe Menu structure recorded in ADR-0193: Keyframe Creation and Insertion, Curve and Tangent, Easing-to-Bézier Simulation, and Time and Removal.

The common menu contains Edit Properties, Cut, Copy, Duplicate, Delete, and Move Playhead Here. Numeric keyframes place creation and insertion actions in Keyframe Creation and Insertion, interpolation and tangent actions in Curve and Tangent, valid Easing-to-Bézier conversion in Easing-to-Bézier Simulation, and time/removal actions in Time and Removal. The menu exposes only interpolation modes supported by the final verified animation data model. Command Animation Effect Events do not display interpolation commands or any numeric-keyframe-only action. For a multi-node selection, an operation targets the complete selection by default; an action that cannot validly apply to every selected item is hidden or visibly disabled rather than partially mutating an unspecified subset.

Property edits, cut, duplication, deletion, interpolation changes, and other project-content changes enter the normal Undo/Redo history as atomic gestures. Copy and Move Playhead Here do not change project content and therefore do not enter Undo/Redo. Deletion requires no additional confirmation and remains recoverable through Undo. Any action that would overwrite an existing same-track, same-lane, same-time node still follows the established grouped overwrite-confirmation and server revalidation rules.
