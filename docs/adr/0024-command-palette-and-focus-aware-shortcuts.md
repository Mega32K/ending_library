# Provide a searchable command palette with focus-aware shortcuts

The editor exposes a searchable Command Palette, opened by a configurable default shortcut such as `Ctrl+K`, and lists commands from file/project lifecycle, editing, playback, tracks, keyframes, curves, snapping, Preview Stage, collaboration, workspaces, import/export, and recovery. Each result includes its category, current shortcut, availability, and disabled reason. Users may edit a Shortcut Profile, receive immediate conflict details, explicitly cancel/remove/swap compatible bindings, and restore defaults; unresolved shortcut conflicts are not persisted. Shortcut profiles are player-local preferences and never enter project revisions.

Shortcut Routing is mandatory. When a rename, text, numeric, menu, or other focused editor control owns input, its editing semantics take priority over global commands. Otherwise the active Panel Focus routes the gesture to the timeline, viewport, inspector, command palette, or global editor action, with the most specific eligible scope taking precedence. Default bindings include play/pause, frame stepping, Undo/Redo, focus selection, work-range marking, and command-palette opening, but implementation must verify conflicts against the live Minecraft keymap before assigning final defaults.
