# Preserve dormant data but switch curve modes directly

Changing a Curve Segment among `BEZIER`, `EASING_PRESET`, `LINEAR`, and `CONSTANT` changes the active evaluation mode immediately and does not attempt to preserve the previous mode's rendered trajectory. Dormant Curve Data remains stored while another mode is active and is restored when the segment returns to `BEZIER`. If no dormant curve exists, the editor creates a fresh editable Bézier shape directly: there is no approximation report, conversion dialog, Bézier baking, or automatic insertion of intermediate keyframes. The confirmed mode change and any required default-data initialization form one server-validated project transaction and one Undo/Redo item, while the selected Easing remains available as the explicit Legacy Easing Fallback.
