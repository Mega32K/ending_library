# Author curve handles with normalized time and track values

Bézier handle Time is authored within each Curve Segment as a normalized `0` to `1` coordinate and displayed as `0%` to `100%`; entering `35` therefore means `35%`. The start and end handle times must remain forward ordered, while handle Value uses the owning track's actual unit and may exceed either keyframe value to support overshoot. The project authoring model retains finite values in double precision, formats fields with up to six useful decimal places without discarding submitted precision, and performs a validated conversion only when publishing to the current float-based runtime or a legacy format. A materially lossy conversion must be disclosed rather than silently accepted. Dragging remains a live local preview and commits as one Undo/Redo operation only when the gesture is confirmed.
