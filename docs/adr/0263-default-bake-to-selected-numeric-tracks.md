# Default Bake to selected numeric tracks

Bake resolves one explicit Bake Track Scope and defaults to `Selected Tracks`. Eligible targets are populated, evaluable Scalar Animation Tracks in the Current Edited Animation; selecting a Track Group expands to its eligible populated numeric children, but no empty track is created merely because its parent is selected. When the current selection resolves no eligible track, Bake is disabled with the reason shown through the established tooltip and tool-surface feedback.

The tool offers `All Populated Numeric Tracks` as an explicit alternative rather than a default fallback. Command Animation Effect Events and Project Timeline Markers are never baked, Timeline Channel Visibility and hidden-empty-channel presentation never affect target resolution, and Bake never converts between `TRANSLATION_*` and `RELATIVE_*` coordinate families. The Tool Operation Preview lists every included track and every excluded selected target with its reason. Confirmation re-resolves the exact track identities and structure on the server; a structural change after preview creation rejects the candidate instead of silently expanding, shrinking, remapping, or partially baking its scope.
