# Keep conversion fallback at range level

An accepted Easing-to-Bézier Simulation retains its original Easing interval or intervals as range-level compatibility metadata rather than copying one `easing` value onto every ordinary converted node. This Conversion Source Fallback Range is inactive during Bézier evaluation, is not rendered as a special node state, and cannot trigger hidden regeneration. The new project format remains authoritative for the current Bézier chain. A time, value, or curve edit affecting the converted range marks the fallback stale; a Legacy Animation Format export must then present an explicit warning and require the user's choice to continue with the old source Easing or cancel. The exporter must not silently report the stale fallback as equivalent to the edited Bézier result.
