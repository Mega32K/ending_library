# Require an interior node for nonlinear Easing conversion

An Easing-to-Bézier conversion preserves the source interval endpoints and applies a minimum node rule before adaptive fidelity refinement. A source interval whose evaluated result is linear may remain as its two endpoint Timeline Bézier Nodes and intentionally render as `LINEAR`. Every non-linear source interval, including constant, bounce, elastic, and other non-affine presets, must receive at least one ordinary inserted interior node, producing at least two active Bézier intervals; adaptive sampling may add more nodes to satisfy the selected global fidelity target. The inserted node retains ordinary editing semantics, is included in the preview count, and is never regenerated automatically after the conversion transaction.
