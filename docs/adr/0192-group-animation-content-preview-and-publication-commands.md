# Group animation content, preview, and publication commands

The top toolbar exposes an Animation Menu with three visibly separated command groups: Animation Content, Editor Preview, and Runtime Publication. The menu derives availability from the active Project Tab, current animation selection, participant role, accepted revision, Active Runtime Revision, UI Client Player runtime instance, validation state, and relevant collaboration state. Disabled commands remain visible when useful and explain the current blocking reason through the shared tooltip contract.

Animation Content contains New Animation, Properties, Rename, Duplicate, and Delete. These commands use the same implementations as the Animation Resource Browser and animation-item context menu. Successful content changes are ordinary server-authoritative Edit Operations, create Project Document revisions, and enter the initiating player's Personal Edit History. Broad deletion retains its existing confirmation and destructive-preflight rules.

Editor Preview contains Preview Current Animation, Enable Published Animation for Me, and Stop Enabled Animation for Me. Preview Current Animation may evaluate the current editor working content through the isolated editor-preview path and does not publish it. Enable Published Animation for Me is restricted by the Published Runtime Gate, starts or transactionally replaces a Project Runtime Instance only for the UI Client Player, and begins at time zero. Stop Enabled Animation for Me performs Runtime Stop only for that player's instance and is not pause. These commands never target another player or create project-content revisions.

Runtime Publication contains Publish Current Accepted Revision, the equivalent active-revision replacement state when a revision is already published, and Stop Published Runtime Application. Publication uses only a selected valid server-accepted revision; local property previews, submitted-but-unacknowledged gestures, command drafts, and other local content drafts are excluded without being discarded. Publication remains Lock-Neutral and does not implicitly start a runtime instance when none exists.

Every publish, active-revision replacement, and project-runtime stop creates a bounded Runtime Publication Record containing actor, time, selected accepted revision where applicable, operation type, and outcome. These records are available through the project history surface and retention filters, but are not Project Document revisions, personal Undo/Redo items, command-input history, or an unbounded runtime diagnostic stream.

The Animation Menu contains no save, checkpoint, recovery, archive, project import/export, or editor-preference commands. Context menus remain compact shortcuts to the valid per-animation subset and never hide publication as a silent side effect.
