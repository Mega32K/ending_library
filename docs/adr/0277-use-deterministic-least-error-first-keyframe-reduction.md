# Use deterministic least-error-first keyframe reduction

Remove Redundant Keyframes uses Deterministic Least-Error Reduction rather than chronological deletion or an unbounded search for the globally smallest key set. Lane endpoints, non-candidate nodes, and interpolation-protected nodes are fixed anchors. At each step the optimizer simulates every currently eligible deletion and measures the complete provisional result against the immutable trajectory captured at the start of the operation, never against the already simplified intermediate result.

A candidate's score is the greatest normalized fidelity consumption produced by that provisional result across every affected Additive Lane and accumulated Scalar Animation Track: each applicable relative or actual-unit error is divided by its Trajectory Fidelity Profile limit, with inapplicable near-flat relative checks omitted. The lowest-scoring candidate whose complete provisional result still passes is accepted, affected neighboring candidates are rescored, and the process repeats until none pass. This prevents iterative error drift and prioritizes removal of the least visually significant nodes.

Equal scores resolve by canonical Track order, Additive Lane order, Timeline Time, and finally stable node identity, so responsive client preview and authoritative server recalculation produce the same candidate set. The final set receives one complete fidelity validation before confirmation. This deterministic greedy method may retain a few nodes that an expensive global combinatorial search could remove; the tool guarantees reproducibility and bounded-quality output, not mathematical minimum cardinality.
