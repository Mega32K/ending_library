# Rebuild collaborator presence after explicit permission rejoin

`Explicit Permission Rejoin` establishes a new collaboration-presence boundary. The client does not restore the previous session's collaborator cursors, playheads, selections, observation cameras, gesture previews, locks, subscriptions, or pending gestures. After the new Editing Session handshake and permission validation complete, the server sends a fresh bounded presence snapshot containing only currently connected participants who are still authorized for the project. The rejoining player's valid local selection and observation state may be restored for local display, but it is not broadcast until the new session is ready. Any unfinished drag, batch gesture, or old collaborator preview is discarded and creates no project revision or personal history entry.
