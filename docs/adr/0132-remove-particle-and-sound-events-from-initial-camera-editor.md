# Remove particle and sound events from the initial camera editor

The initial camera-animation editor and runtime support only Command Animation Effect Events in the Animation Effects group. Particle and sound events are removed from the first-release scope instead of being represented as disabled rows, hidden JSON fields, partial preview controls, or incomplete recipient/position models. This decision supersedes the event-level recipient designs recorded by ADR-0127 and ADR-0129. Existing command-event decisions remain active: commands use their own payload selectors, execute once per runtime crossing from the current target player, use the fixed server permission policy and suppressed output, and remain isolated when execution fails. Any future particle or sound implementation must return as a new design decision covering data format, spatial origin, recipients, preview, looping, and dispatch lifecycle before UI or runtime work begins.
