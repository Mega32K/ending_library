# Structure the keyframe menu into four purpose-built groups

The rewritten Camera Animation Editor organizes the numeric-keyframe context menu into four stable groups instead of presenting a flat list of unrelated actions: Keyframe Creation and Insertion, Curve and Tangent, Easing-to-Bézier Simulation, and Time and Removal. The first group covers creating, inserting, duplicating, and related authored-node actions; the second covers Curve Interpolation Mode and applicable Bézier Tangent Mode; the third opens the bounded, preview-first Easing-to-Bézier simulation flow; and the fourth covers time movement, moving the playhead, deletion, and clearing selected timeline-track data. Actions are shown only when they are valid for the complete current selection, while Command Animation Effect Events retain their own type-appropriate menu and never receive numeric-keyframe-only actions.

Every project-content action from these groups uses the existing server validation, permission and collaboration conflict rules, grouped selection semantics, overwrite confirmation where applicable, duration auto-extension rules, and one Edit Gesture Transaction with one personal Undo/Redo item. Copying, moving the playhead, and other view-only actions remain history-neutral. Deletion and Clear Timeline never shorten Animation Duration implicitly, and opening or navigating the menu never adds hover decoration or persistent controls to the clean timeline row.
