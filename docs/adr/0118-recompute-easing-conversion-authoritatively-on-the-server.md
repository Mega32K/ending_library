# Recompute Easing conversion authoritatively on the server

The Easing Conversion Preview computes its candidate immediately on the client from the current project snapshot so fidelity changes and diagnostic rendering remain responsive. Confirmation submits the source conversion range, baseline revision, fidelity target, conversion-algorithm version, and bounded budget request rather than treating the client-generated nodes as authoritative. The server reruns the same deterministic algorithm, validates source data, fidelity, payload, and resource limits, and commits only its verified complete result as one collaboration revision and one personal Undo/Redo item. If the client candidate differs from the server result, the server result is authoritative and the client refreshes the preview before any later confirmation. Preview computation remains temporary and bounded; rejection creates no project mutation or partial conversion.
