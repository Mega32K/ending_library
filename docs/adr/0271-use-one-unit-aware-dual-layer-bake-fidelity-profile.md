# Use one unit-aware dual-layer Bake fidelity profile

One Bake operation selects one Bake Fidelity Profile for every participating Scalar Animation Track and Additive Lane rather than exposing independent per-lane tolerances. The profiles are High Precision (`0.1%` relative error, `0.001` block, `0.01°`), Balanced (`0.5%`, `0.005` block, `0.05°`) as the default, Draft (`2%`, `0.02` block, `0.25°`), and Custom. `X/Y/Z`, `TRANSLATION_*`, `RELATIVE_*`, `ZOOM`, and `RAYCAST` use block-unit caps; `ROTATION_*` and `FOV` use degree-unit caps. Custom exposes the relative target and only the unit-cap fields relevant to the resolved Bake Track Scope.

Every participating Additive Lane must satisfy both its applicable relative tolerance and actual-unit cap, and the accumulated Scalar Animation Track produced by Lane Accumulation must independently satisfy the same profile. This preserves authored layer shape while also protecting the value used at runtime, preventing errors from being hidden through cancellation between lanes. Relative scale is derived from the source interval's actual excursion and extrema rather than endpoint difference alone; a flat or numerically near-flat interval avoids unstable percentage division and is judged by its actual-unit cap.

Adaptive Error-Bounded Bake deterministically refines the greatest failing lane or accumulated-track error until every applicable check passes; budget exhaustion or an unmet target blocks confirmation. Fixed Interval measures against the same profile as its recommended threshold but follows the explicit warning path in ADR-0270. The Tool Operation Preview groups diagnostics by Track and Lane and reports relative error, actual-unit error, maximum-error time, applicable limits, and pass state. Server confirmation recomputes the same profile against the authoritative baseline, and no client-only tolerance, hidden per-lane override, or silent threshold relaxation is permitted.
