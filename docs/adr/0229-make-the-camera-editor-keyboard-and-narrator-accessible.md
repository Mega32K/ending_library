# Make the camera editor keyboard and narrator accessible

The rewritten Camera Animation Editor follows one `Editor Accessibility Contract`. Every button, menu, list, tree, property field, popup, modal, drawer, panel entry point, status detail, and recovery action is reachable and operable by keyboard. Focus uses a clearly visible non-color-only treatment and follows the current responsive visual order rather than a fixed coordinate list. `Enter` or Space activates suitable controls, arrow keys navigate menus and structured lists, and `Esc` closes or cancels only the highest active overlay or gesture according to its existing contract. When a text editor owns focus, cursor movement, selection, insertion, deletion, completion, and confirmation keys are routed to that editor before global shortcuts.

Selection, focus, locks, warnings, errors, synchronization, permission, Auto Key, collaborator, and runtime states combine color with text, icon, shape, border, or another semantic cue. Tooltips remain supplementary; every explanation available only after pointer hover is also reachable through focus, a status/detail surface, or contextual help. The existing Standard Dark and High-Contrast Dark themes preserve these semantics.

Minecraft narration describes controls, fields, blocking decisions, and meaningful status transitions. Rapid playhead updates, timeline scrubbing, collaborator cursors, gesture previews, progress changes, and world-overlay motion are throttled and coalesced rather than narrated per frame. Dense timeline and world-space nodes are not automatically enumerated; the current selection, Property Inspector, Timeline Track Tree, and Status Detail Surface expose a structured accessible summary of the focused item and its state.

A player-local `Reduce UI Motion` preference removes or shortens menu, drawer, tooltip, notice, panel, and selection-transition animation while preserving immediate state feedback. It does not modify authored camera animation timing, interpolation, Local Preview, Collaborative Preview, runtime playback, trajectory evaluation, or world-space camera motion. Accessibility preferences are device-local editor preferences and never project content or synchronized collaborator state.
