# Keep easing presets while adding editable curve segments

The first release of the rewritten editor retains every existing `Easing` value as a named compatible preset and implements a first-class optional custom curve segment for each interval between neighboring keyframes. A custom segment may use editable cubic Bézier control points and is evaluated identically from the authoritative Project Format, Extended Camera Animation JSON, collaborative preview, and runtime playback. When no custom curve field exists, the original `easing` meaning remains unchanged.

Importing an unversioned easing-only JSON file maps its easing values to compatible curve presets. Extended Camera Animation JSON stores optional versioned custom curve data while retaining an explicit Legacy Easing Fallback for readers that do not understand the extension. A Legacy Animation Format export deliberately omits custom curve data; if an exact legacy preset cannot represent the segment, the editor displays a downgrade warning and requires an explicit user decision rather than silently discarding or approximating the curve. Project documents remain the complete multi-channel collaborative source.
