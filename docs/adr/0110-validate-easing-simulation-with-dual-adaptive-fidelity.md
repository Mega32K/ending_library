# Validate Easing simulation with dual adaptive fidelity

Easing-to-Bézier Simulation evaluates every source interval with adaptive samples concentrated around extrema, rapid changes, and excursions that can disappear when the endpoint values are equal. The candidate is checked against both normalized Easing output error and error in the owning track's real authored unit; the selected fidelity presets remain `0.1%` high precision, `0.5%` balanced, `2%` draft, or a custom threshold. A range is marked below target when any interval fails either check. The user may explicitly confirm a below-target candidate after a prominent warning, but non-finite values, sampling failure, or a hard server collaboration/resource limit disable confirmation and preserve the source Easing data. The complete accepted conversion remains one server-validated revision and one Undo/Redo operation.
