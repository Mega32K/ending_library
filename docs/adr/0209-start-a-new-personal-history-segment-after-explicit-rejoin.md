# Start a new personal history segment after explicit permission rejoin

`Explicit Permission Rejoin` starts a new empty `Editing Session History Segment` because the previous Undo/Redo entries were authored against the frozen tab's former document baseline and may refer to released locks, subscriptions, identities, or revisions. The previous segment is not migrated, rebased, merged, or allowed to operate on the freshly loaded authoritative document. During the same connected lifecycle it may remain available as a collapsed, read-only history reference showing bounded operation summaries, but its Undo and Redo actions are disabled. The grouped Reconnect Draft Review Surface creates no personal history entries; only ordinary editing after the review gate completes populates the new segment. A failed rejoin leaves the old segment attached to the frozen tab, and Connection Lifecycle Exit clears both segments with the rest of the ephemeral editor state.
