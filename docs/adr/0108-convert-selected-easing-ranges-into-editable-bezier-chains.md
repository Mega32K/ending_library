# Convert selected Easing ranges into editable Bézier chains

The Keyframe Menu's Easing-to-Bézier Simulation group exposes this conversion only when the selected endpoints define one valid continuous Easing Conversion Range.

The timeline context menu exposes `Convert to Bézier` only when exactly two selected keyframes define one continuous Easing Conversion Range on the same scalar track. Every interval from the first selected timestamp through the second must use `EASING_PRESET`; mixed interpolation modes, cross-track selections, and any other selected-node count disable the action. Intermediate Easing keyframes are included automatically and retain their stable identity, authored time, and authored value, while per-interval adaptive conversion may insert additional Timeline Bézier Nodes needed to simulate each source Easing interval within the accepted tolerance. Shared source boundaries default to `BROKEN` so adjacent intervals retain independent incoming and outgoing simulation handles. The first endpoint's incoming interval is not part of the range. The complete range becomes one editable Bézier Node Chain, and conversion is one server-validated collaboration revision and one Undo/Redo item.
