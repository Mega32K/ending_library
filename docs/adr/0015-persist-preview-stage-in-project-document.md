# Persist the Preview Stage in the versioned project document

The Preview Stage is project authoring metadata, not a player workspace value. The versioned Project Document stores its dimension identifier, world position, orientation, reference FOV, zoom and raycast baseline, label, and capture metadata. Capturing or changing the stage is a server-ordered edit operation, increments the authoritative project revision, and is broadcast to every active editing session participant.

Creating a project may capture the creator's current camera as the initial stage. Reopening the project reconstructs the same stage, so relative tracks and camera-volume visualization remain deterministic. If a Collaborative Preview is active, later accepted stage metadata edits remain live project revisions but do not replace the active `Collaborative Preview Stage Snapshot` until the Preview Leader performs a validated Preview Stage Switch. If the stored dimension cannot be loaded, the editor uses an Abstract Stage Preview with an explicit warning; it never silently substitutes a participant's current position. Legacy JSON conversion does not silently invent a stage field: legacy export omits the stage or uses an explicitly selected conversion context and reports the limitation.
