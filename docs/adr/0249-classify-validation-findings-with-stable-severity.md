# Classify validation findings with stable severity

Every Validation Finding has a stable semantic Validation Severity. `Error` means the checked content is invalid, structurally contradictory, non-finite, missing required data, or unusable for the checked runtime or target format; it predicts that a related publish, export, or runtime action should be rejected by that action's own authoritative validation, but it does not prevent continued editing by itself. `Warning` means the content remains valid but carries a likely visual discontinuity, compatibility or precision loss, risky configuration, or resource-budget concern, while `Information` is a correctness-neutral observation or optimization opportunity.

Severity belongs to the diagnostic definition and cannot be changed by the user, report filters, or client localization. The client localizes only the stable diagnostic code and bounded arguments; repeated findings are grouped by that code rather than rendered text, and a successful report uses its header summary instead of generating one Information finding for every passed check. Validation remains advisory and read-only; publication, export, import, and runtime activation independently revalidate the current authoritative content rather than trusting an earlier report.
